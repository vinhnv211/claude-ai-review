[DHCP-001] Buffer overflow khi parse option 82 với length > 255

options.c:142-158 · parse_option82() · agent dhcp-review-agent · category: security · confidence: high 
if (opt->code == 82) {
    memcpy(ctx->relay_buf, opt->data, opt->len);
    ctx->relay_len = opt->len;
}

Impact: Attacker gửi DHCP packet với option 82 dài > 255 byte → stack/heap corruption → DoS hoặc RCE.

Fix: Thêm check if (opt->len > sizeof(ctx->relay_buf)) return -EINVAL; trước memcpy.
